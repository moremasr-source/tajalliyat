# تجليات الأسماء

موقع لأسماء الله الحسنى: تجلٍّ يومي، وعشرون اسماً لست فئات (طفل، طفلة، شاب، شابة، أب، أم)، ورحلة ١٤٠ يوماً، وقسم «قلبي الآن» للمشاعر، وتذكير يومي في التقويم، وفيديوهات قصيرة.

> نسخة تجريبية. المحتوى يحتاج مراجعة عالم شرعي قبل النشر العام.

## التشغيل على GitHub Pages
1. ارفع محتويات هذا المجلد إلى مستودع جديد (الملف `index.html` في الجذر).
2. من **Settings → Pages** اختر: **Deploy from a branch**، الفرع `main`، المجلد `/ (root)`.
3. بعد دقيقة يعمل الموقع على: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

## ما يعمل خارج Claude وما لا يعمل
- يعمل: كل الصفحات، والرحلة (تُحفظ في متصفح الزائر)، وملف تذكير التقويم، والفيديوهات.
- لا يعمل بعد: تسجيل الرسائل اليومية (يحتاج خادماً وخدمة إرسال، في النسخة الكاملة).

## المصدر (`source/`)
- `data/*.json`: بطاقات الأسماء والمشاعر، وهي المكان الوحيد لتعديل المحتوى.
- `build.py`: يتحقق من عدد العناصر (١٠ أسئلة، ٢٠ تجلياً، ٢٠ مهمة لكل فئة)، ويجلب نص كل آية حرفياً من المصحف، ثم يكتب `data.js`.
  يحتاج نص المصحف: `npm install quran-json@3.1.2` داخل مجلد `vendor/`.
- `video/engine.html` و`render.js` و`audio.py`: قالب الفيديوهات (Playwright + ffmpeg)؛ `node render.js rahman` ثم `python3 audio.py rahman out.wav`.
